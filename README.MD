## Market Basket Analysis API
Этот проект представляет собой микросервис на базе FastAPI, который использует алгоритм Apriori для анализа рыночной корзины. Он выявляет ассоциативные правила между товарами в транзакциях (например, «покупатели, которые берут товар А, часто берут и товар Б»).

### Установка
Клонируйте репозиторий:
```
git clone https://github.com/KirillYarv/MLCoreAPI.git
cd MLCoreAPI
```

Дальнейший запуск выполняется через Docker Compose.

### Запуск приложения
Запуск сервера разработки осуществляется с помощью uvicorn. Выполните следующую команду в терминале:

```uvicorn main:app --reload```

- main - это имя вашего Python-файла (без .py).
- app - это экземпляр FastAPI внутри этого файла.
- --reload - флаг для автоматической перезагрузки сервера при изменении кода (полезно при разработке).

После запуска сервер будет доступен по адресу: http://127.0.0.1:8000

### Запуск через Docker Compose
Запустите сервисы из корня проекта:

```bash
docker compose up --build
```

Для запуска в фоне:

```bash
docker compose up --build -d
```

Остановка сервисов:

```bash
docker compose down
```

### Требования для GPU (ALS)
- На хосте должен быть установлен NVIDIA Driver с поддержкой CUDA 12.2.
- Рекомендуемый минимум: драйвер ветки 535+ (например, 536.25 и выше).
- Для Docker нужен NVIDIA Container Toolkit (для `docker compose` с GPU).

Проверка доступности GPU внутри контейнера:

```bash
docker compose run --rm python_app python3 -c "from implicit import gpu; print(gpu.HAS_CUDA)"
```

После запуска API будет доступно по адресу: http://127.0.0.1:8001

Важно: внутри контейнера приложение подключается к Postgres по хосту `host.docker.internal`.

### API Endpoints
1. Получение ассоциативных правил
URL: _/api/pairs_

- Метод: GET
- Описание: Возвращает список найденных комбинаций товаров (пар/троек) с высоким уровнем поддержки и достоверности.

2. Поиск связанных товаров по названию
URL: _/api/pairs/{product_name}_

- Метод: GET
- Параметры пути: `product_name` - название товара для поиска связей.
- Описание: Возвращает связанные товары, встречающиеся в ассоциативных парах с указанным товаром.

3. ALS-рекомендации
URL: _/api/als/recommendations/{user_id}?top_k=12_

- Метод: GET
- Параметры пути: `user_id` - идентификатор пользователя.
- Query-параметры: `top_k` - количество рекомендаций на пользователя (по умолчанию 12).
- Описание: Возвращает рекомендации ALS для конкретного пользователя.
- Если пользователь не найден, API возвращает ошибку с причиной `user_not_found`.

4. Документация
Swagger UI: _/docs_ - интерактивная документация для тестирования API.

5. Проверка подключения к БД
URL: _/db/isconnect_

- Метод: GET
- Описание: Проверяет подключение к Postgres и возвращает JSON со статусом и сообщением.
